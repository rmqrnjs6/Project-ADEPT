# Project-ADEPT
"사람의 마음의 대한 '행복'은 무엇인가."

## 사용 코드

아래 내용은 「그들의 세계」의 현재 제작본 `dist/index.html`을 확인한 기준입니다.

| 기술 | 사용 내용 |
|---|---|
| HTML5 | 화면 구조, 영역별 콘텐츠, 버튼과 선택 항목 |
| CSS | 색상, 레이아웃, 반응형 화면, 선택 상태와 동작 효과 |
| JavaScript (Vanilla JS) | 마음·정보량 선택, 영역 추천, 조각별 탐험, 예시 보기, 이전 단계, 쉬기·재개 |
| 브라우저 기본 API | DOM 조작과 이벤트 처리, `scrollIntoView`, `Set` |

HTML·CSS·JavaScript는 하나의 HTML 파일에 포함되어 있습니다. 별도 프레임워크, 외부 JavaScript/CSS 라이브러리, CDN, 외부 폰트는 사용하지 않았으며 글꼴은 시스템 기본 글꼴입니다. 현재 제작본에는 AI 모델 API 호출이 없습니다.

## 코드 및 콘텐츠 출처

| 구분 | 출처 |
|---|---|
| 기획·요구사항 | 권기원(Kwon Gi Won)이 대화에서 제시한 「그들의 세계」의 목적과 탐험 방식 |
| 코드 작성 | 해당 요구사항을 바탕으로 OpenAI ChatGPT의 AI 지원으로 생성한 HTML·CSS·JavaScript |
| 외부 코드 | 현재 제작본에서 외부 패키지 의존성·외부 스크립트 로딩·외부 코드 인용 표기는 확인되지 않았습니다. 별도 외부 코드를 가져오지 않았다는 제작 기록에 따릅니다. |
| 콘텐츠 | 대화에서 확인한 권기원의 적심(適心)·명확(明確), 판단·검증·협업 경험과 AI·UI/UX·UML 기초 설명 |
| 업로드 자료 | 강의자료 및 분석 PDF 전체는 현재 제작본에 반영되지 않았습니다. |
