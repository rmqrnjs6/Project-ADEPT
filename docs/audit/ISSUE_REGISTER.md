| ID | 우선순위 / 확실성 | 관찰 / 영향 | 다음 검증 |
|---|---|---|---|
| A-001 | P2 / 후보 | 21행 chips(), 22행 paint()가 replaceChildren으로 선택 버튼을 매번 교체. 키보드 포커스 연속성에 영향 가능 | 브라우저에서 Tab→선택→다음 Tab의 포커스 위치 확인. 현재 BLOCKED, 결함 확정 아님 |
| A-002 | P3 / 코드 확인 | 23행 read()에 조각 개수 3, [0,1,2], level<2가 반복됨 | 콘텐츠가 가변 길이가 될 요구가 생기면 pieces.length 기준 검토. 현재 3개 고정 콘텐츠 자체를 결함으로 판정하지 않음 |

## 학습 포인트

리뷰에서는 결함, 설계 선택, 미확인 후보를 나눕니다. 버튼이 교체되는 코드를 읽은 사실은 있지만 실제 키보드 사용자가 길을 잃는지까지는 아직 확인하지 않았습니다. 재현 전에는 후보로 남겨야 합니다.

한 파일 구성이나 숫자 3이 있다는 이유로 즉시 분리하지 않습니다. 이 사이트가 모든 영역에서 정확히 3조각을 제공하는 고정 기획이라면 의도된 값입니다. 영역마다 조각 수가 달라지는 요구가 생길 때 수정 범위를 비교하면 됩니다.

후속 브라우저 TC: 마음 선택 시 aria-pressed/추천 갱신, 영역 선택/발견 수 중복 방지, 3조각 이전·다음, 예시 보기, 쉬기→현재 조각 재개, 440px 화면, 키보드 포커스. 모두 현재 NOT_RUN 또는 브라우저 부재로 BLOCKED이며 PASS가 아닙니다.
